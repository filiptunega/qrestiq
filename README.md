# 🍽️ Qrestiq

A complete restaurant management and ordering system with iOS client applications and a Node.js/Express backend server.

---

## 📋 Overview

Qrestiq is a modern restaurant ordering platform that provides a seamless experience for both customers and staff. The project includes:

- **iOS Customer App** (`iosApp/`) - For restaurant customers to browse menus and place orders
- **iOS Staff App** (`iosAppStaff/`) - For restaurant staff to manage orders and operations
- **Backend Server** (`server/backend/`) - Express.js REST API with PostgreSQL database

---

## 🎯 Features

### Customer App
- Browse restaurant menus
- Place and track orders

### Staff App
- Manage incoming orders
- Update order status
- Restaurant operations dashboard

### Backend
- RESTful API built with Express.js
- Secure authentication with JWT and bcrypt
- PostgreSQL database integration
- Error handling and logging

---

## 🛠️ Tech Stack

### Frontend
- **iOS**: Swift
- **WEB**: html, css, js

### Backend
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: PostgreSQL
- **Authentication**: JWT (jsonwebtoken)
- **Security**: bcrypt
- **Development**: Nodemon (hot reload)
